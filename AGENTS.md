# Agents

## Git rules

- Commit often: roughly every hundred lines changed, the way you would save a file.
- Every commit message is one sentence, written as a Conventional Commit with a scope and no body, for example `feat(lang): add Polish language`.
- Follow the Conventional Commits standard: a lowercase type (`feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `perf`, `style`, `build`, `ci`), a scope in parentheses, a colon and a space, then an imperative, lowercase description with no trailing period. Mark breaking changes with `!` before the colon.
- Push once all the code for the task is done.
- Never co-author: no `Co-Authored-By` trailers or other attribution lines in commits or pull requests.
